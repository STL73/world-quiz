# Screenshots

Drop screenshots in this directory using the following names so the README renders them automatically:

| Filename | What to capture |
| --- | --- |
| `landing.png` | Landing page hero — top of `index.php`, ideally with the floating glass nav and the eyebrow pill visible. Width ~1600px. |
| `quiz.png` | Quiz gameplay — `quiz.php` mid-question, hint either revealed or not. Show the landmark image, the question, three answer options, and the token badge in the top bar. |
| `dashboard.png` | User dashboard — `user_panel.php` showing the welcome hero, star token count, and quick action cards. |
| `admin.png` | Admin panel — either `admin_panel.php` (dashboard stat cards) or `view_questions.php` (the per-question grid). The latter looks more impressive. |

## Recommended capture settings

- Browser zoom 100%
- Window width 1440–1600px (matches the design system's primary breakpoint)
- Use the browser's "Capture full size screenshot" feature for clean output without OS chrome
- Save as PNG (sharper than JPEG for UI screenshots)

Once you've added the four files, this README can be deleted — the placeholder paths in the project README will start rendering real images.
